Strategy Shift: Desktop App → Web App
======================================

Background
----------
Versions 0.x.x shipped as a bundled desktop application (.app on macOS,
.exe on Windows) using PyInstaller + a Streamlit UI served locally. This
approach introduced persistent issues:
  - A second browser tab opening on its own mid-run, triggering a false
    "foreign worker" heartbeat warning.
  - Complex launcher logic (server.lock, headless mode quirks, macOS
    App Translocation) that was brittle and hard to debug.
  - Users needing to install/rebuild a native binary for every update.

Decision
--------
Starting with version 1.0.0, the app ships as a pure web application
hosted on Streamlit Community Cloud (share.streamlit.io), reachable at
a subdomain of centrallinegroup.com via Namecheap DNS.

Rationale
---------
  - Zero installation for the user: open a URL, done.
  - No launcher, no webbrowser.open(), no tab management — the browser
    tab issue disappears entirely.
  - Updates deploy instantly via a GitHub push; no rebuild required.
  - Free hosting on Streamlit Community Cloud for public repos.
  - The Keepa API key is entered in the sidebar UI and never stored in
    the repo, so a public GitHub repo is safe.

Trade-offs accepted
-------------------
  - If the browser tab is closed mid-run, the background worker dies.
    Recovery is handled by the existing resume feature (last_run.json).
  - The app sleeps when no browser is connected; wakes on next visit.
  - Compute is limited to Community Cloud's 1 GB RAM / 1 CPU allocation,
    which is sufficient since Keepa API rate limits (1 token/min) are
    the real bottleneck.

Version plan
------------
  0.x.x  — Desktop app era (PyInstaller, macOS .app, Windows .exe)
  1.x.x  — Web app era (Streamlit Community Cloud, centrallinegroup.com)

Files removed in 1.0.0
-----------------------
  desktop_launcher.py   — macOS/Windows process launcher
  sa-rebuild.spec       — PyInstaller build spec
  packaging/            — build-mac.sh, build-windows.bat

Files added in 1.0.0
--------------------
  requirements.txt          — pip dependencies for Streamlit Cloud
  .streamlit/config.toml    — server settings (upload size, headless, etc.)
